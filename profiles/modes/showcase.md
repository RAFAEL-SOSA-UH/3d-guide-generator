# Mode: video of the result (showcase, turntable, timelapse)

The source shows the finished object, maybe the process sped up or without explanation. Freedom: **medium**.

- First list what the video shows: the object from several angles, any visible stages of the process (in a timelapse, the order in which parts appear is a strong hint).
- Split the object into parts, as in image mode, using all the views available (several angles make proportions and hidden sides much more reliable than a single image).
- Reconstruct the order: visible stages become `Source: deduced` sections; everything in between is `Source: proposed`.
- Estimate real dimensions from the views and say what you used as reference.
- The Video map lists the moments worth watching to compare (a good angle, a stage of the timelapse).
