# Common problems

| Symptom | See |
|---|---|
| I pressed something and can't see anything / it got hidden | `Alt+H` (unhide all) or `Numpad /` (leave local view) |
| I can't select anything | Check you are in the right mode (`Tab`) and that it is not disabled in the Outliner |
| A shortcut does nothing | The mouse must be over the right editor (for example `I` over the 3D view, not over the timeline) |

Add every new problem here and as a note using the **Problem** template.
