# Resources

Files, not notes: .blend files, textures, reference images, PDFs, models. The AI can read them but does not modify or delete them without permission. Not uploaded to git.

```
resources/
  Courses/
    <course>/            what the course gives you + your .blend files for that course
  YouTube/
    <project>/           your files for a single-video project
  Library/               what you reuse in any project
    Textures/  HDRI/  References/  Models/  Palettes/
```

- Same course names as in `guides/` and `ai/Sources/`, so everything is found the same way.
- The instructor's final files (`_final.blend`) are useful to compare when something does not work.
- If you work on a file the course gave you, save a copy with another name to keep the original.
